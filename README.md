# Personal Finance Tracker

A Python-based application that helps users track income, expenses, and savings.

## Features
- Input monthly income
- Record multiple expenses
- Calculate:
  - Total expenses
  - Savings
  - Highest expense
  - Average expense
- Save records to file
- Display past records

## How to Run
1. Download the project
2. Open terminal in the folder
3. Run:

```bash
python t01.py
```

## Example Output

```
=== Personal Finance Tracker ===

Total Expenses: $1785.00
Savings: $1215.00
Highest Expense: $900.00
Average Expense: $223.12
```
